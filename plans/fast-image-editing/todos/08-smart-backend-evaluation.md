前置依赖：01-foundation.md。可与 02–07 并行；禁止修改 Rust 核心、Cargo 配置、公共 README 或其他实现任务的产品文件。

要做什么：在独立 docs/smart-backend/ 与 scripts/smart-backend/ 中调查当前硬件/已配置运行时，仅检查凭据是否存在或配置位置而不输出秘密。依据用户指定（若有）或可用本地模型评估自动抠图、主体分割、对象移除修复、生成填充和扩图。核对模型许可、版本、资源需求、真实协议、输入尺寸/区域/蒙版、支持参数、超时/进度和能力声明；查技术资料只使用官方/论文等一手来源。可以使用本地现有运行时或公开可获取模型，不能擅自购买服务或使用未知账户。对实际可运行候选做真实输出、冷加载/连续暖调用和区域保真/边缘评估，区分模型下载/加载/推理/远端排队。输出供 09/10 实现的明确接口，不用 mock 结果声称模型成功。

- [ ] 三类智能任务均有候选与可用性结论、具体版本/许可来源、资源要求和可复现的运行方法。
